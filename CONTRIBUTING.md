# Contributing

Thanks for contributing to Karen Leather.

## Development

The active storefront lives in `karenleather-web/`.

```bash
cd karenleather-web
npm install
npm run dev
```

Before opening a pull request:

```bash
npm run build
```

## Pull requests

Keep changes focused and include:

- what changed and why
- testing notes
- screenshots for visible UI changes
- deployment or content-migration impact
- any security implications

Never commit credentials, `.env` files, private customer data, database exports, or WordPress secrets.
